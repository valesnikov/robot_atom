# Jetson — Управление роботом через компьютерное зрение

Детектирует позу человека с камеры через MediaPipe, преобразует ключевые точки
в управляющие сигналы и отправляет их на Arduino по Serial.

### Цикл программы (RobotApp.run)

1. **Захват кадра** — чтение с камеры через CameraHandler.
2. **Команды с Arduino** — читается Serial, обрабатываются mirror/reset/screenshot.
3. **Детекция позы** — PoseModule.process() находит landmarks тела через MediaPipe.
4. **Нормализация (worldLandmarks)** — landmarks центрируются относительно торса
   и масштабируются так, чтобы расстояние между плечами стало ~0.26.
5. **Отправка (только в режиме mirror)** — 7 байт: маркер, высоты рук,
   углы плеч, центр торса, масштаб.
6. **Отображение** — кадр с наложенным скелетом и FPS.

### Формат посылки на Arduino (7 байт)

| Байт | Значение | Диапазон |
|------|----------|----------|
| 0 | Маркер начала (1) | — |
| 1 | Высота правой руки (запястье — плечо) | 0..1 |
| 2 | Высота левой руки (запястье — плечо) | 0..1 |
| 3 | Угол правого плеча | 20°..180° |
| 4 | Угол левого плеча | 20°..180° |
| 5 | Центр торса (x) | 0..1 |
| 6 | Масштаб / 5 | 0..1 |

Значения упаковываются в байты 2..255 линейным отображением (toByte).

Автоматический выход из mirror: когда оба угла плеч > 160°.

### Команды с Arduino

- **mirror** — включить режим отслеживания и отправки позы (switch = 1).
- **reset** — выключить режим отправки позы (switch = 0).
- **screenshot** — сохранить текущий кадр в `screenshots/{timestamp}.jpg`.

## Компоненты

- `main.py` — точка входа, класс RobotApp.
- `CameraHandler.py` — сканирование /dev/video*, подключение к камере.
- `SerialHandler.py` — сканирование /dev/ttyUSB* / /dev/ttyACM*, чтение/запись,
  heartbeat-проверка связи.
- `PoseModule.py` — детекция позы через MediaPipe Tasks API (новая версия).
- `PoseModuleJetson.py` — детекция позы через mediapipe.solutions.pose
  (старый API, для Jetson с mediapipe 0.8.5).

При запуске сперва пробуется `PoseModule`, при неудаче — `PoseModuleJetson`.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python3 main.py
```
