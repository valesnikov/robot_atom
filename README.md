# Атом

Проект управления роботом «Атом». Система состоит из Arduino-прошивки и приложения для NVIDIA Jetson, которое использует камеру и компьютерное зрение для отслеживания позы человека.

## Как взаимодействуют части проекта

Jetson получает изображение с камеры, распознаёт позу человека с помощью MediaPipe и преобразует её в управляющие данные. Эти данные передаются на Arduino по последовательному порту.

Arduino управляет аппаратной частью робота: сервоприводами, моторами, RGB-светодиодом и дисплеем. Помимо команд от Jetson, прошивка поддерживает готовые движения и управление кнопками.

Обмен между компонентами происходит через Serial со скоростью `115200` бод:

- текстовые команды используются для служебных операций и переключения режимов;
- в режиме «зеркало» передаются бинарные пакеты с параметрами движения.

## Структура репозитория

```text
.
├── Arduino/
│   ├── app/          # исходный код прошивки
│   ├── libs/         # архивы библиотек Arduino
│   ├── Makefile      # сборка, прошивка и монитор порта
│   └── README.md     # подробности об Arduino-части
├── Jetson/
│   ├── *.py          # приложение компьютерного зрения и обмена с Arduino
│   ├── requirements.txt
│   └── README.md     # подробности о Jetson-части
└── README.md         # общий обзор проекта
```

## Быстрый запуск

Подробные инструкции по установке зависимостей, подключению оборудования, сборке и запуску находятся в README соответствующих подпапок.

1. Подготовить Arduino и установить библиотеки из `Arduino/libs/`.
2. Собрать и прошить Arduino-приложение.
3. Установить Python-зависимости для Jetson.
4. Подключить Arduino и камеру к Jetson.
5. Запустить приложение из каталога `Jetson`.
