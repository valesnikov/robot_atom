# Атом (Arduino)

Прошивка для платы Arduino, управляющая роботом. Код написан на C++ (Arduino) и принимает команды от одноплатного компьютера (Jetson) по последовательному порту, а также поддерживает автономный режим «зеркало».

## Структура проекта

```
.
├── app/                  # Исходный код прошивки
│   ├── app.ino           # Главный файл: точка входа, обработчики команд, главный цикл
│   ├── activ.h           # Готовые движения робота (удары, повороты и т.д.)
│   ├── buttons.h         # Чтение шести кнопок с одного аналогового пина
│   ├── config.h          # Конфигурация: пины, адреса PWM, границы сервоприводов
│   ├── diode.h           # Управление RGB-светодиодом (глаз робота)
│   ├── log.h             # Вывод логов на TFT-дисплей с цветовой кодировкой
│   ├── mirror.h          # Режим «зеркало»: повтор движений, ПИД-регулятор головы
│   ├── motors.h          # Управление двумя моторами с плавным разгоном
│   ├── pid.h             # Простой ПИД-регулятор
│   ├── serial.h          # Асинхронное чтение команд из Serial-порта
│   ├── servo.h           # Класс сервопривода с диапазонами и инверсией
│   ├── state.h           # Переключение режимов робота (NONE, MIRROR)
│   └── utils.h           # Утилиты: разбор строк, конвертация байтов, парсинг чисел
├── libs/                 # ZIP-архивы сторонних библиотек для установки
└── Makefile              # Сборка, прошивка и мониторинг через arduino-cli
```

## Аппаратное обеспечение

Прошивка рассчитана на плату **Arduino Uno** (ядро `arduino:avr`).

### Основные компоненты

| Компонент | Описание |
|---|---|
| **Плата** | Arduino Uno (ATmega328P) |
| **Драйвер PWM (PCA9685)** | Управление сервоприводами и RGB-светодиодом по I2C |
| **Сервоприводы** | 7 шт.: пояс, правая рука (2 оси), левая рука (2 оси), голова |
| **Моторы** | 2 коллекторных мотора (левая/правая сторона) с ШИМ-управлением |
| **TFT-дисплей** | Экран ILI9341 для вывода логов |
| **Кнопки** | 6 кнопок, подключённых через резисторный делитель к одному аналоговому пину A2 |
| **RGB-светодиод** | Светодиод «глаза» робота (красный/зелёный/синий каналы через PWM) |
| **ИК-приёмник** | Пин 3 (зарезервирован в конфигурации) |

### Назначение пинов

| Пин | Назначение |
|---|---|
| 4, 7, 8 | TFT: CS, RESET, DC |
| 5, 6 | Мотор правый: вперёд, назад |
| 9, 10 | Мотор левый: вперёд, назад |
| A2 | Кнопки (аналоговый делитель) |
| 3 | ИК-приёмник (зарезервирован) |

### PWM-каналы PCA9685

| Канал | Назначение |
|---|---|
| 0 | Пояс |
| 1, 2 | Левая рука: горизонтально, вертикально |
| 3, 4 | Правая рука: горизонтально, вертикально |
| 5, 6, 7 | RGB-светодиод: красный, зелёный, синий |
| 8 | Голова |

## Режимы работы

Робот работает в одном из двух режимов (`State`):

- **NONE** — режим ожидания команд. Обрабатываются команды из последовательного порта. Светодиод светится синим.
- **MIRROR** — режим «зеркало». Робот повторяет движения оператора, передаваемые по Serial байтовым протоколом (6 байт на кадр). Угол поворота головы стабилизируется ПИД-регулятором. Светодиод светится зелёным.

Переключение в режим MIRROR выполняется командой `mirror` из Serial-порта или кнопкой 4. Выход из режима MIRROR — передача байта `0` по Serial или кнопка 3 (сброс в NONE).

## Команды Serial

Скорость: **115200 бод**. Команды — текстовые строки, разделённые переводами строк.

| Команда | Описание |
|---|---|
| `heartbeat` | Проверка связи. Робот отвечает `heartbeat` |
| `print <текст>` | Вывод текста от Jetson в лог |
| `motors <R> <L>` | Установить целевые скорости моторов, от −255 до 255 (плавный разгон) |
| `mirror` | Переключение в режим «зеркало» |
| `flash` | Вспышка белым светодиодом на 100 мс |

В режиме MIRROR используется бинарный протокол: кадр начинается с байта `1`, затем 6 байт данных, значения конвертируются функцией `byte2Val` (диапазон 2–255; байты 0 и 1 — управляющие). Порядок байт в кадре:

1. Правая рука, вертикально (0..1)
2. Левая рука, вертикально (0..1)
3. Правая рука, горизонтально (0..1)
4. Левая рука, горизонтально (0..1)
5. Угол поворота головы (−1..1)
6. Дистанция до объекта (0..1) — используется, если раскомментирован `saveDistance()`

## Кнопки

| Кнопка | Действие |
|---|---|
| 1 | Заглушка (логирование) |
| 2 | Заглушка (логирование) |
| 3 | Сброс: переключение в режим NONE (`reset`) |
| 4 | Переключение в режим «зеркало» (отправляет `mirror` в Serial) |
| 5 | Удар — следующее движение из расписания `punch()` |
| 6 | Проверка связи (отправляет `heartbeat` в Serial) |

Кнопки опрашиваются через аналоговый делитель напряжения на пине A2. Уровень напряжения определяет номер нажатой кнопки (точность 3%, антидребезг 500 мс).

## Управление сервоприводами

Класс `Servo::set(float angle)` принимает значение в диапазоне **−1 … 1**:

- `0` — стандартное (среднее) положение;
- `1` — максимальное положение;
- `−1` — минимальное положение.

Диапазоны и инверсия каждого сервопривода задаются в `config.h` (структура `ServoBounds`).

## Готовые движения (`activ.h`)

| Функция | Описание |
|---|---|
| `none()` | Сброс всех приводов в нулевое положение |
| `r_huk()` / `l_huk()` | Хук правой / левой рукой |
| `r_aperkot()` / `l_aperkot()` | Апперкот правой / левой рукой |
| `meln()` | Вращение пояса («мельница») |
| `r_MAX()` / `l_MAX()` | Полный разворот с ударом (максимальная амплитуда) |
| `set_right()` / `set_left()` | Поворот головы и пояса вправо / влево |
| `punch()` | Следующее движение по кругу из расписания ударов |

## Логирование

Логи выводятся на TFT-дисплей (ILI9341) с цветовой кодировкой по уровню:

| Уровень | Цвет |
|---|---|
| Trace | Серый |
| Debug | Голубой |
| Info | Зелёный |
| Warn | Жёлтый |
| Err | Красный |
| Fatal | Розовый |

Макросы: `LOG_T`, `LOG_D`, `LOG_I`, `LOG_W`, `LOG_E`, `LOG_F`.

## Требования для сборки

- [arduino-cli](https://arduino.github.io/arduino-cli/) в `PATH` **или** [Arduino IDE](https://www.arduino.cc/en/software)
- Ядро `arduino:avr` (Arduino AVR Boards)
- Библиотеки (ZIP-архивы в `libs/`):
  - [Adafruit BusIO](https://github.com/adafruit/Adafruit_BusIO)
  - [Adafruit GFX Library](https://github.com/adafruit/Adafruit-GFX-Library)
  - [Adafruit ILI9341](https://github.com/adafruit/Adafruit_ILI9341)
  - [Adafruit PWM Servo Driver Library](https://github.com/adafruit/Adafruit-PWM-Servo-Driver-Library)

### Установка библиотек

В Arduino IDE: **Скетч → Подключить библиотеку → Добавить .ZIP библиотеку…** и по очереди выбрать архивы из каталога `libs/`.

Или через CLI:

```bash
make install-libs
```

## Сборка и прошивка

### Через Arduino IDE

1. Установите [Arduino IDE](https://www.arduino.cc/en/software).
2. Добавьте поддержку платы: **Инструменты → Плата → Менеджер плат…** → установите **Arduino AVR Boards**.
3. В меню **Инструменты → Плата → Arduino AVR Boards** выберите **Arduino Uno** и укажите правильный порт в **Инструменты → Порт**.
4. Установите библиотеки из `libs/` (см. выше).
5. Откройте файл `app/app.ino` в Arduino IDE.
6. Нажмите кнопку **Загрузка** (→), чтобы скомпилировать и прошить робота.

### Через arduino-cli

| Команда | Действие |
|---|---|
| `make setup` | Установка ядра Arduino AVR |
| `make build` | Компиляция прошивки в `build/` |
| `make flash PORT=/dev/ttyUSB0` | Прошивка на плату |
| `make monitor PORT=/dev/ttyUSB0` | Монитор последовательного порта (115200 бод) |
| `make install-libs` | Установка библиотек из `libs/` |
| `make clangd` | Генерация compilation database для clangd |
| `make clean` | Удаление каталога `build/` |
